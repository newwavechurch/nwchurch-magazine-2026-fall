# 새물결교회 계간지 가을호 e-book 에셋

`더이웃 SNS` 가을호(새물결교회 50주년 기념 계간지)를 웹 플립북으로 보여주기 위한
정적 에셋 모음이다. 인디자인 PDF 한 벌에서 페이지 이미지 · 썸네일 · 검색 텍스트 ·
목차 · 배경음악을 뽑아내 그대로 GitHub Pages 에 올릴 수 있게 만든다.

## 재생성

```
python scripts/build-assets.py
```

몇 번을 실행해도 같은 결과가 나온다. 입력 원본(PDF · mp3)의 경로는
`scripts/build-assets.py` 상단 상수(`SRC_PDF`, `SRC_MP3`)에 있으며,
스크립트는 원본을 읽기만 한다.

필요 도구: Python 3.10+, PyMuPDF, Pillow, ffmpeg.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `pages/p001.webp` ~ `p076.webp` | 단면 페이지 이미지 (1200px 폭) |
| `thumbs/p001.webp` ~ `p076.webp` | 썸네일 (240px 폭) |
| `data/book.json` | 책 메타데이터 (제목 · 쪽수 · 이미지 크기 · 경로 패턴) |
| `data/search.json` | 페이지별 본문 텍스트 `[{ "page": 1, "text": "..." }]` |
| `data/toc.json` | 섹션 목차 `[{ "title": "...", "page": 5 }]` |
| `audio/bgm.mp3` | 배경음악 (128kbps 재인코딩) |

원본 PDF 는 표지 · 뒤표지가 단면, 나머지가 펼침면이다. 펼침면은 정확히 좌/우
절반으로 잘라 두 장으로 만들고, 텍스트도 단어의 중심 좌표를 기준으로 좌/우에
나눠 담는다. 목차의 `page` 는 이렇게 만든 단면 번호(1~76) 기준이다.

## 페이지 보정

원본 PDF 조판 오류를 이미지 단계에서 고친 것은 `scripts/patch-*.py` 로 남긴다.
`build-assets.py --force` 로 페이지를 다시 만든 뒤에는 이 스크립트들을 다시 실행해야 한다.

| 스크립트 | 내용 |
| --- | --- |
| `scripts/patch-p015.py` | 15쪽 본문 마지막 줄 "…되었습" 뒤에 잘린 "니다." 복원 (같은 페이지 글리프 복사) |
